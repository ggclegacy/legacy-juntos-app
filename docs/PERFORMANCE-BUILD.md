# Performance implementation blueprint

One program format, three entry paths: manual, imported, AI draft. Both accounts have identical capabilities; optional prep never dictates the program. This supersedes the earlier coach-first framing. Programs and completed sessions are separate documents; sessions snapshot prescriptions so edits never alter history. Typed nested documents are appropriate for atomic program/session editing at this scale; separate indexed owner/workspace/type/revision columns enforce access and concurrency. Future analytics can normalize exercise events without changing the editor contract.

Research: MacroFactor's [builder](https://help.macrofactorapp.com/en/articles/286-create-a-new-program-via-build-from-scratch) demonstrates optional complexity and common execution for all program sources. [Boostcamp](https://www.boostcamp.app/custom-program) supports multiweek authoring; [Alpha Progression](https://alphaprogression.com/en/blog/alpha-progression-guide) keeps generated plans editable. Use these patterns rather than separate trackers. [IndexedDB guidance](https://web.dev/learn/pwa/offline-data) supports transactional drafts; [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) places ownership at the database boundary. Connected writes use revision checks, and conflicts require user resolution rather than last-writer-wins.

Build sequence: typed program/session/prep contracts; owner-only database and API; durable device drafts with explicit consent; editor and reviewed text/JSON import; configured AI generation with schema validation; gym execution and history; prep and check-in export; critical permission/concurrency/model/browser verification. AI has no write tools and returns a draft only. A missing AI credential is an honest unavailable state, never simulated generation.

V1 scope: rotating ordered sessions repeated for a chosen number of cycles, editable exercise prescriptions and advanced set labels, recovery notes, posing practice notes, show milestones, downloadable check-in. Later: per-cycle overrides, automatic calendar scheduling, full spreadsheet/PDF/photo extraction, media storage and timestamped video feedback, coach portal/grants, wearable integrations, automatic progression rules, richer exercise education. Never claim these integrations exist before implementation.
